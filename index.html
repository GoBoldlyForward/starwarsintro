starwarsintro.css

A pure CSS library for the Star Wars-style intro crawl. No JavaScript dependencies.

What it is

Drops a Star Wars-style scrolling intro crawl onto any page using pure CSS animations. Use it for fan sites, movie marathons, browser-game intros, presentations — anywhere the recognizable crawl effect fits.

Requirements

HTML and CSS. That's it — no JavaScript, no other dependencies.

Install

Download starwarsintro.css from this repo. (An npm package is coming, pending a rename.)

Usage

<!-- In document head -->
<link rel="stylesheet" href="/path/to/starwarsintro.css">

<!-- In body where you want the intro -->
<div class="star-wars-intro">

  <p class="intro-text">A few days ago, during...</p>

  <h2 class="main-logo">
    <img src="img/your-logo.png">
  </h2>

  <div class="main-content">
    <div class="title-content">
      <p class="content-header">EPISODES IV-VI<br>A Movie Marathon</p>

      <p class="content-body">
        Your scrolling story here…
      </p>
    </div>
  </div>
</div>

You'll also need a star-field background image at img/stars-bg.jpg (included in this repo).
